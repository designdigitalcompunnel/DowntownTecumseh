Downtown Tecumseh Website Concept
================================

Included pages
- index.html: Homepage
- services.html: Events & Activities inner page (repurposed from the original services page as requested)

Assets and structure
- css/style.css: Original stylesheet retained and extended with Downtown Tecumseh brand styles.
- css/accessibility.css: Original accessibility stylesheet retained.
- js/main.js: Existing interactions retained with search element references updated.
- js/tecumseh.js: Event filtering, grid/list view toggle, search overlay, mobile navigation and reveal animations.
- assets/images/tecumseh-logo.png: Logo supplied in the conversation.
- assets/images/footer-mark.svg: Original Compunnel footer mark retained.

Brand palette
- Deep Tecumseh Blue: #1C4866
- Muted Blue-Gray: #60869B
- Warm Heritage Gold: #CF964B
- Soft Blue-Gray: #D9E2E7
- White: #FFFFFF

Content note
The Events page uses official event details for the upcoming Gather & Give Back Holiday Open House (Nov. 21, 2026) and Christmas Parade & Santa (Dec. 4, 2026) as found on the official Downtown Tecumseh website at the time of preparation. Other category cards are discovery pathways rather than claims of dated events. Confirm live dates, details, image permissions, and event submission workflows before production.

Images use distinct external Unsplash URLs per page. Internet connection is required for remote photos and Google Fonts.

Footer updates: four grouped link columns; social-media access icons; light-theme Compunnel logo uses assets/images/footer-mark-light.svg; Events header links to the top of the Events page.

Latest accessibility and media refinements
- Gold/brown CTA buttons use dark-brown text (#2B1A0A) on #CF964B (contrast ratio approximately 6.47:1); hover buttons use white text on #9C5A0B (approximately 5.41:1).
- Art Trail CTA now has a visible outline and a subtle abstract circular motif.
- Homepage and Events hero use remote Pexels stock video with poster images as fallback. Video requires an internet connection; browsers honoring reduced-motion preferences receive the static image fallback.
- Accessibility options close when the user clicks or taps outside the panel.
- Stock video source pages: https://www.pexels.com/video/quiet-street-in-a-small-town-with-stores-29731292/ and https://www.pexels.com/video/a-crowd-of-people-at-a-festival-in-a-park-27978752/.

Latest refinement (October 2026):
- Restored the Art Trail section to a more comfortable desktop height (380px) while keeping a compact stacked mobile layout.
- Improved header search with six popular-search chips and live matching results for the site's events, Art Trail, Farmers Market, local shopping and dining, business opportunities, DDA, community updates, and contact information.
- Search results update as visitors type; selecting a result opens the matching page/section. The search overlay also closes with Escape, the close control, or a click on the backdrop.
